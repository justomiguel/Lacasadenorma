# Medios

Vistas previas de notas de prensa enlazadas desde `/que-paso`. No son
fotografías de la familia: viven acá y no en `public/fotos/` para que
`check:fotos` no las mezcle con el retrato de Norma.

Cada archivo se declara en `content/{es,en}/que-paso.json` con sus
dimensiones reales. Los títulos de las notas los escribimos nosotros.
